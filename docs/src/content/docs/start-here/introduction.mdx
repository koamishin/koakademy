# KoAkademy developer documentation

KoAkademy is a self-hosted school administration and learning platform. It is a production-capable beta: the repository provides a supported topology and automated validation, while each operator remains responsible for staging, backup, monitoring, privacy, and recovery.

## Self-Host or Contribute?

For self-hosting, begin with [Installation](./installation/), then follow [Deployment](./docker/) and [Configuration](./configuration/). The supported default is one HTTPS hostname with administration at `/admin`.

For source development, start with [Development](../development/) and [Contributing](./contributing/). Root technical Markdown files are canonical; marked MDX pages are generated with `npm run docs:sync`.

## Production services

| Role | Supported component |
| --- | --- |
| HTTP application | KoAkademy production image, PHP 8.5, FrankenPHP |
| Database | PostgreSQL |
| Cache, sessions, queue | Redis |
| PDF rendering | `spatie/laravel-pdf` with Gotenberg |
| Uploads | External S3-compatible storage |
| HTTPS | Operator-managed Caddy, Nginx, Traefik, or tunnel |

Only the latest stable release is supported. KoAkademy is licensed under GNU AGPL-3.0-or-later.
