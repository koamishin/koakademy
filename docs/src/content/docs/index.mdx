## For school staff

Start with the **User Guide**, then follow the Enrollment Blueprint guides when you need to configure enrollment. These pages explain the effect of each choice, recommended defaults, safe publication, and what changes only future enrollments.

## For technical teams

Use **Developer Docs** for server requirements, Docker, environment configuration, source-code contribution, handler registration, and testing. Use **API Reference** for integration contracts.
